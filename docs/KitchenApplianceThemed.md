# 厨电制造专题大屏 · 设计文档

> 面向管理大屏的制造业（厨电行业）专题系列，沿用本仓库「公共资金专题」的三层范式
> （见 [`PublicFundsThemed.md`](PublicFundsThemed.md)）。本文是开发前的设计基线：
> 系列结构、虚构企业与数据设定、青橙配色公共样式、每页版式与指标勾稽、工程约定。
> 数据全部为编造的模拟数，每页挂「模拟数据」标识；真实口径由后端接口提供，本文不涉及。

---

## 1. 项目定位与范围

- **行业设定**：厨电制造集团，总部杭州，全国视角（多基地生产、全国仓网、全国门店 + 线上全渠道）。
- **规模**：**21 块屏** = 1 门户 + 12 专题页（自动轮播）+ 8 二级详情子页，一次性全量交付。
- **目录**：`screens/kitchen-appliance/`，页面互链为同目录相对路径；目录需同步加进
  `tools/build_index.py` 的 `CONTENT_DIRS`。
- **形态**：纯自包含单文件样板间（不套壳），1920×1080 舞台 + `fitStage()` 等比缩放，
  数据全内联，echarts 走 CDN。全部照抄 `CLAUDE.md` 样板间范式。

### 21 块屏总表

```
门户（1）
  └─ 经营驾驶舱：集团 KPI + 12 页导航宫格 + 产销存全景 + 经营健康雷达 + 风险清单
        │
专题页（12，按业务顺序串成自动轮播）
  ├─ 一期 · 供应与制造（4）  原料采购总览 / 供应商协同 / 生产制造总览 / 品质管理
  ├─ 二期 · 仓储与流通（4）  仓储库存 / 物流运输 / 门店零售 / 电商全渠道
  └─ 三期 · 营销与服务（4）  营销活动 / 售后服务 / 用户会员运营 / 经营健康指数（收官）
        │
子页（8，从专题页下钻进入）
  基地生产详情 / 供应商台账 / 库存库龄台账 / 物流线路详情 /
  省区门店分布 / 单品销售详情 / 售后工单台账 / 故障部件分析
```

### 三段式叙事骨架

| 段 | 回答的问题 | 视觉重心 |
|---|---|---|
| 一期 · 供应与制造 | 造不造得出、造得好不好 | 价格区间带、甘特、直通率漏斗，强调「过程」 |
| 二期 · 仓储与流通 | 存得多不多、运得快不快、卖到哪里 | 仓网地图、流向线、渠道桑基，强调「分布与流向」 |
| 三期 · 营销与服务 | 卖得动不动、用户满不满意、经营健不健康 | 转化漏斗、工单甘特、合成指数雷达，强调「转化与边界」 |

## 2. 虚构企业与数据设定

公开仓库，主体必须虚构：**「云麓厨电集团」**（虚构品牌，总部杭州）。
命名刻意不与任何真实厨电企业相近；页面不出现真实品牌、真实人名。

### 2.1 业务设定（所有页面共用的世界观）

- **六大产品线**：吸油烟机 / 燃气灶具 / 洗碗机 / 蒸烤一体机 / 集成灶 / 净水热水。
- **三大生产基地**：杭州临平（总部主基地：烟机、灶具）、安徽芜湖（洗碗机、蒸烤）、
  广东佛山（集成灶、净水热水）。另设「成都基地（在建）」作叙事彩蛋，不计产能。
- **七大区域仓（RDC）**：华东-杭州、华北-天津、华南-佛山、华中-武汉、西南-成都、
  东北-沈阳、西北-西安。基地→RDC 干线 + RDC→省区配送两级物流。
- **渠道**：线下门店（KA 卖场 / 品牌专卖店 / 建材集合店，覆盖 31 省）+
  线上全渠道（京东 / 天猫 / 抖音 / 苏宁易购 / 品牌自营，模拟平台一律用真实平台名之外可斟酌，
  开发时若避讳则改「平台A/B」式虚指——**默认用真实平台名**，属公开常识不涉脱敏）。
- **五大原材料**：冷轧板 / 不锈钢 / 铜材 / 面板玻璃 / 电子电控件。
- **供应商**：约 180 家，分战略（S）/ 优选（A）/ 合格（B）/ 观察（C）四级。

### 2.2 核心数字（当年度基准盘，全系列勾稽的单一数据源）

| 口径 | 数值 | 派生关系 |
|---|---|---|
| 年营收 | 112.6 亿元 | = 线下 48.4 + 线上 58.7 + 工程渠道 5.5 |
| 年销量 | 866 万台 | = 六产品线之和；单价×销量与营收对得上量级 |
| 年产量 | 902 万台 | = 三基地之和；产量 − 销量 ≈ 库存净增 + 在途 |
| 成品库存 | 118 万台 | 期初 + 产量 − 销量 = 期末，逐月滚动成立 |
| 门店数 | 3 240 家 | = 31 省之和 |
| 会员数 | 1 860 万 | 注册→绑定→活跃逐层递减 |
| 年售后工单 | 96.8 万单 | ≈ 保有量 × 年故障率，与「品质管理」页市场故障率同源 |
| 供应商 | 182 家 | = S 12 + A 45 + B 98 + C 27 |

**勾稽铁律**（延续仓库范式）：合计 = 分项之和；比率、达成率、占比一律 JS 现算不复制数字；
跨页共用的数字（产量、销量、库存、故障率、门店数）在各页取同一基准值，
月度序列可各页自编但年度合计必须回到上表。

## 4. 视觉语言：青橙配色公共样式

### 4.1 气质定位

与公共资金专题的「藏蓝 + 金」区分：制造业用**深青黑底 + 工业青主色 + 工业橙强调**。
青 = 设备指示灯 / 精密仪器的冷静与秩序；橙 = 炉火、警示、产线活性。
橙同时承担「暖色告警 / 目标线 / 强调」三职，红色只留给真告警。

### 4.2 公共色板（系列级 token，`--mfg-*` 前缀）

配色是**系列公共样式**：所有 21 页使用同一组 `--mfg-*` 变量名与同一份 JS 镜像
`const PAL = {...}`，后续整套换色只改一处源、批量同步（见 4.3）。

| token | 值 | 用途 |
|---|---|---|
| `--mfg-bg` | `#051416` | 页面暗底（深青黑） |
| `--mfg-stage` | `#071b1e` | 舞台底 |
| `--mfg-panel` | `rgba(14,46,50,.55)` | 卡片面板底 |
| `--mfg-line` | `rgba(64,196,190,.22)` | 面板描边 / 分隔线 |
| `--mfg-cyan` | `#35e0d0` | 主色：主指标、主系列、高亮 |
| `--mfg-cyan-deep` | `#1a9e96` | 主色深阶：次系列、渐变下端 |
| `--mfg-blue` | `#4fa8e8` | 辅色：对比系列（保留一点蓝与全仓库呼应） |
| `--mfg-green` | `#7ee08a` | 正向：达成、合格、增长 |
| `--mfg-orange` | `#ff9d45` | 工业橙：强调、目标线、暖色叙事 |
| `--mfg-amber` | `#ffc94d` | 橙黄：次强调、库龄中档 |
| `--mfg-red` | `#ff5f6b` | 真告警：超限、失败、缺货 |
| `--mfg-violet` | `#a98cf5` | 补充系列色（桑基/旭日多分类时） |
| `--mfg-text` | `#d8f2ef` | 主文字 |
| `--mfg-text-dim` | `#7fa6a3` | 次文字 / 轴标签 |

分类序列色顺序：`cyan → orange → blue → green → amber → violet`（多系列图按此取色）。

### 4.3 换色机制（公共样式的落地方式）

页面保持自包含，但色板做成**可批量同步**：

- 单一色源：`shared/palette-manufacturing.json`（上表的 JSON 形式，另含 `_series` 分类序列色顺序）。
- 每页的 `:root{ --mfg-* }` 块与 `const PAL = {...}` 镜像都包在成对标记注释里，
  命名沿用仓库既有的 `xxx:begin / xxx:end` 惯例（同 `mockflag:begin`）：
  CSS 侧 `/* mfgpalette:begin */ … /* mfgpalette:end */`，
  JS 侧 `/* mfgpalette-js:begin */ … /* mfgpalette-js:end */`。
  `PAL` 之外另有一层手写的便利别名 `const C`（驼峰访问 + 衍生色），**不在同步块内**。
- 新增工具 `tools/sync_mfg_palette.py`：读色源 JSON，把 `screens/kitchen-appliance/`
  下所有页面标记区内的色板整体重写（幂等，可反复跑）。后续换整套配色 = 改 JSON + 跑脚本。
  `--remove` 只清块内容、保留标记本身（标记是页面结构的一部分，删了下次无处落笔）。
- 布局类 class/id 仍按每页唯一 2 字母前缀隔离，**只有色板 token 共用 `--mfg-` 前缀**。

### 4.4 其余视觉规范

字体、数字字形（翻牌缓动）、卡片圆角描边、扫描线/呼吸光带等活性动画、
CSS grid 模拟表格、徽章 `.xx-badge.is-xxx`——全部沿用公共资金专题规范，不再另立。

## 5. 每页设计规格

以下每页给出：回答的问题 / 版式 / 核心图表 / 关键指标与勾稽 / 下钻。
版式基线：左中右三栏或左右双栏，页头 KPI 带，页头正中留空给「模拟数据」标识。

### 门户 · 经营驾驶舱（前缀 `kd`）

- **问题**：集团今年经营怎么样，风险在哪，从哪看起。
- **版式**：顶部 6 枚集团 KPI（营收 / 销量 / 产量 / 库存周转 / 市场故障率 / NPS）；
  中部左「产销存全景」三联柱线（产量、销量、库存逐月，勾稽 2.2 平衡式），
  中「12 页导航宫格」（4×3，每格小图标 + 页名 + 一枚微型指标），
  右「经营健康雷达」（六维：交付/质量/库存/渠道/服务/增长，与收官页同源）；
  底部「关键风险清单」滚动条目（缺货 SKU、超期库龄、故障率抬头、物流延误线路）。
- **下钻**：宫格 → 12 专题页。

### 一期 · 供应与制造

**P1 原料采购总览（`yc`）**
- **问题**：大宗材料价格走势如何、采购成本可控吗、料够不够。
- **图表**：五大原材料价格三年月度走势 + 历史区间带（镜像「土地出让形势」的区间带做法）；
  采购额结构瀑布（按材料类）；库存覆盖天数五联温度计（安全线 = 橙色目标线）；
  采购降本达成子弹图。
- **勾稽**：采购额合计 = 五材料之和；覆盖天数 = 材料库存 ÷ 日均耗用（JS 现算）。

**P2 供应商协同（`gx`）**
- **问题**：供应商队伍质量如何、谁在拖后腿。
- **图表**：全国地图供应商分布（省级气泡，按级别着色）；
  准时交付率 × 来料合格率散点四象限（镜像「客户价值分层矩阵」，四色按 S/A/B/C）；
  齐套率月度走势；观察级（C 级）供应商预警表。
- **勾稽**：182 家 = 四级之和；四象限点数 = 有考核数据的供应商数。
- **下钻**：→ 供应商台账。

**P3 生产制造总览（`zz`）**
- **问题**：产得出来吗、计划达成没有、产线效率如何。
- **图表**：三基地产量动态排序柱（逐月回放）；六产品线计划达成子弹图；
  基地×产品线产能甘特（镜像「现金管理」14 期甘特，含今日线）；OEE 三联仪表（按基地）。
- **勾稽**：902 万台 = 三基地之和 = 六产品线之和（两个维度都收敛到同一总量）。
- **下钻**：→ 基地生产详情。

**P4 品质管理（`pz`）**
- **问题**：质量链每一段守住没有、缺陷集中在哪。
- **图表**：来料合格率 → 制程直通率 FPY → 出厂检验合格率 → 市场故障率 四段质量漏斗
  （本页招牌图，四段贯穿原料到售后）；缺陷类型帕累托（柱 + 累计占比线）；
  市场故障率 24 月走廊带（目标带内青色、越界橙/红）；六产品线 FPY 小多图。
- **勾稽**：市场故障率 × 保有量 ≈ 售后年工单量（与售后页同源）。
- **下钻**：→ 故障部件分析。

### 二期 · 仓储与流通

**P5 仓储库存（`ck`）**
- **问题**：存了多少、压在哪、周转健康吗。
- **图表**：全国地图七大 RDC 仓网（气泡 = 库存量，颜色 = 利用率档位）；
  库龄结构瀑布（0-30 / 31-60 / 61-90 / 90+ 天，90+ 用红）；
  库存周转天数 24 月走势 + 行业参考带；六产品线库存 × 动销率散点。
- **勾稽**：118 万台 = 七仓之和 = 四库龄段之和 = 六产品线之和。
- **下钻**：→ 库存库龄台账。

**P6 物流运输（`wl`）**
- **问题**：货在路上跑得顺不顺、时效达成没有。
- **图表**：全国地图两级流向线（基地→RDC 干线粗线、RDC→省区配送细线，lines 系列）；
  时效达成率日历热力（月视图）；干线 / 配送 / 尾程三段时长堆叠条；
  在途量 + 破损率双轴走势。
- **勾稽**：在途量与 P5 库存平衡式衔接；线路条数 = 3 基地×7 仓 + 7 仓×覆盖省区。
- **下钻**：→ 物流线路详情。

**P7 门店零售（`md`）**
- **问题**：线下卖得怎么样、哪些省强哪些省弱。
- **图表**：31 省销售额 choropleth（主图 + 南海小地图，见 §6）；
  同店增长 × 坪效省区象限散点（镜像「收入-增速象限」）；
  三渠道类型（KA / 专卖店 / 建材店）结构环形；门店数月度净增柱（开店正、闭店负）。
- **勾稽**：线下 48.4 亿 = 31 省之和 = 三渠道类型之和；3 240 家 = 省区之和。
- **下钻**：→ 省区门店分布。

**P8 电商全渠道（`ds`）**
- **问题**：线上盘子多大、哪个平台哪个品类在增长、直播转化如何。
- **图表**：渠道桑基（线上总盘 → 5 平台 → 6 产品线）；
  直播转化漏斗（曝光→进店→加购→成交）；平台×产品线增速热力矩阵；
  大促节奏日历热力（618 / 双 11 峰值叙事）。
- **勾稽**：线上 58.7 亿 = 5 平台之和 = 桑基各层守恒；与 P7 合计回到 2.2 渠道结构。
- **下钻**：→ 单品销售详情。

### 三期 · 营销与服务

**P9 营销活动（`yx`）**
- **问题**：投入产出划不划算、新品打得响不响。
- **图表**：活动 ROI 排序条（按 campaign，橙色基准线 = 盈亏线）；
  投放结构旭日（媒介→平台）；新品上市节奏时间轴 + 首销 30 天爬坡小多图；
  品牌声量 × 转化双轴走势。
- **勾稽**：营销费用合计 = 各 campaign 之和；新品销量计入 P7/P8 对应产品线。

**P10 售后服务（`sf`）**
- **问题**：工单接得住吗、修得快不快、用户满意吗。
- **图表**：工单流转甘特（受理→派单→上门→完结，含超时橙色段）；
  及时率三联仪表（24h 响应 / 48h 上门 / 一次修复）；
  故障类型旭日（产品线→部件，厨电部件层级天然适配）；满意度 24 月走势 + 投诉率。
- **勾稽**：96.8 万单 = 六产品线之和 ≈ 保有量×故障率（与 P4 同源）。
- **下钻**：→ 售后工单台账。

**P11 用户会员运营（`yh`）**
- **问题**：用户资产多大、活跃吗、复购吗。
- **图表**：会员漏斗（注册 1 860 万 → 绑定设备 → 年活跃 → 年复购）；
  会员等级金字塔 + 各级 ARPU；新增会员来源桑基（渠道→会员）；
  复购间隔分布直方 + NPS 仪表。
- **勾稽**：漏斗逐层递减；NPS 与门户 KPI 同值。

**P12 经营健康指数（`jk`，收官页）**
- **问题**：整体健康度多少分、哪个维度在失血。
- **图表**：加权合成大仪表（六维加权总分，直接镜像「资金运行指数」）；
  六分项雷达（交付/质量/库存/渠道/服务/增长，与门户雷达同源同值）；
  指数 24 月 K 线；加权明细可追溯表（每维的权重、原始指标、得分，JS 现算总分）。
- **勾稽**：总分 = Σ(分项 × 权重)，明细表可逐行验算；分项原始指标全部取自 P1–P11 的既有数字。

## 6. 地图专题（全国视角）

- 全部复用 `shared/geo-data.js`，页面内联注册，无外网请求。内联**不手写**，由新增工具
  `tools/inline_geo.py <页面> china` 注入页面预留的 `/* geo:begin */ … /* geo:end */` 块
  （幂等，`--remove` 只清内容保留标记）。`china` 单个数据集约 465KB，人工处理不现实。
- 注意 `china` 是 **35 个 feature**：34 个省级 + 1 个空名要素（`adcode` 为 `100000_JD`，即九段线）。
- 全国图（P2 供应商、P5 仓网、P6 流向、P7 choropleth、`xl`/`sq` 子页）一律照抄
  「主图 + 右下角南海小地图」的既有拆分做法（纬度 17.5° 切分、双 geo 组件）。
- **`aspectScale: 0.75` 显式下发 + 运行时现算 `layoutSize`**，用
  `convertToPixel` 打极点验证不出画布——CLAUDE.md 里最坑的一条，每张地图页都过一遍。
- 流向线页（P6/`xl`）用 `lines` 系列 + `effect` 拖尾，起讫点坐标取省会/基地城市经纬度，
  内联一份小型城市坐标表即可，不需要新增 geo 数据。
- 杭州总部在 P2/P5/P6 地图上挂一枚橙色发光标（呼应「板块首位市加暖橙发光点」的既有手法）。
