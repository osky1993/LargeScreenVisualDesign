## 四、厨电制造专题样板间 `screens/kitchen-appliance/`（35 块）

制造业（厨电行业）专题系列，沿用公共资金专题的三层范式：1 块门户 + 19 块专题页（自动轮播）
+ 15 块二级详情子页。虚构主体「云麓厨电集团」，视觉为深青黑底 + 工业青 + 工业橙。
**设计理念、数据设定与实现范式见 [`KitchenApplianceThemed.md`](KitchenApplianceThemed.md)。**
全系列共用 `--mfg-*` 色板（单一源 `shared/palette-manufacturing.json`，
改色源 + 跑 `tools/sync_mfg_palette.py` 即整套换色）。

三层导航：门户 19 格宫格 → 专题页；专题页底部页码 + 左右箭头 + 25 秒自动轮播（← → 翻页、空格暂停），
页头右上一枚「二级子页」标签直达子页；父页表格行/图形块可点击下钻，跳 `<子页>#<对象名>`，
子页据 hash 直接定位并带「返回上级」链接。由 `inject_carousel_kitchen.py` /
`inject_subnav_kitchen.py` / `inject_drilldown_kitchen.py` 三把脚本注入（幂等，均支持 `--remove`）。

全系列勾稽收敛到同一基准盘：年营收 112.6 亿（线下 48.4 + 线上 58.7 + 工程 5.5）、年销量 866 万台、
年产量 902 万台（= 三基地之和 = 六产品线之和）、成品库存 118 万台（= 七仓 = 六产品线 = 四库龄段）、
门店 3240 家、会员 1860 万、供应商 182 家、保有量 3227 万台、年售后工单 96.8 万单
（= Σ 保有量 × 故障率）、经营健康指数 83.4 分（= Σ 六维 × 权重，与门户雷达同源）。
