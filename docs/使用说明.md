# 使用说明

面向「打开页面看效果、复制配置去用」的日常使用。维护与再生成见 [维护指南](维护指南.md)。

## 数据全部是模拟的

所有样板间（含公共资金专题系列）页面顶边正中挂一枚橙色「模拟数据」标识，页内数字均为
演示用的内联假数据，不对应任何真实业务口径。整批摘掉：

```bash
python3 tools/inject_mock_flag.py --remove
```

## 索引页 `index.html`

收录全部文件，支持按图表类型筛选、按方案名关键词搜索（如搜「霓虹」「渐变」「飞线」直接定位到
具体方案）。顶部筛选 chip 里的 **「公共资金专题样板间」** 是独立分组，只收本条线的成品屏，
不与通用「样板间」混排。

## 复制配置

每张方案卡右上角有「复制配置」按钮，复制出的内容是带注释的可运行 JS 片段（`const option = {...}`），
粘到项目里配 `echarts.init(dom).setOption(option)` 即可使用；若浏览器限制剪贴板会弹窗供手动复制。

## 配色主题

每个实验室页面顶部有「配色主题」下拉，可在 12 套行业主题与 21 套风格皮肤间即时切换（图表色板、
渐变、光效自动重算），点「还原」回到原始配色。切换主题后再复制配置，得到的就是换色后的方案。

## 地图实验室

主图支持 中国 → 长三角 → 江苏 → 苏南/苏中/苏北 四级点击钻取，面包屑可逐级返回；
长三角层和板块层各有「显示地级市」切换按钮。

## 公共资金专题：轮播

13 块专题页页头右上角有一组导航——`‹` 上一页、页码与倒计时条、`›` 下一页、`⏸` 暂停/继续。
默认每页停留 **30 秒**，走完自动翻到下一页，末页回到首页循环。键盘 `←` `→` 翻页、`空格` 暂停。
暂停时进度条冻结在原地，继续时接着走而不是重新计时；标签页切到后台也会自动冻结，回来接着走，
不会一次补跳好几页。

改停留秒数：编辑 `tools/inject_carousel.py` 里的 `seconds=30` 后重跑 `python3 tools/inject_carousel.py`
（幂等）；调整轮播页序或增删页面改同文件的 `PAGES` 列表。撤销导航：`python3 tools/inject_carousel.py --remove`。

## 公共资金专题：二级详情子页

13 个专题页里有 10 个可继续下钻，入口分两种：

- **行级下钻**（江苏地市收入、税收分行业、新动能税收、重点城市与县区、资金余额分析、现金管理）：
  点表格行、卡片、图例行或赛道标签，悬停会高亮并出现 ↗ 角标，进入子页后自动定位到所点对象。
- **面板级入口**（政府债券发行、土地出让形势、收入分项目）：子页是全量台账、没有切换对象，
  故在相关面板头挂一枚青色「逐笔台账 ↗」/「逐宗台账 ↗」chip，点击直接进入。

门户页导航宫格上，可下钻的 8 张卡在序号后带青色「下钻」角标。有的父页挂了两组入口指向不同子页
（江苏地市收入：明细表行→地市详情、板块卡片→三大板块分布；新动能税收：四大类图例→四大类分布、
赛道标签墙→赛道分布），税收分行业与新动能税收还额外把 treemap／环形图的**画布分块**绑成了下钻热区。

子页页头是三级面包屑（第二级可点回父页）+ 对象切换器 + 返回按钮，`←` `→` 切换对象、`Esc` 返回；
子页不参与 13 页轮播。重跑入口注入：`python3 tools/inject_drilldown.py`（`--remove` 可撤销）。

## 公共资金专题：页头「二级子页」标签

13 个专题页页头右上是一枚标签，直接写明本页**有没有**二级子页、子页叫什么、页内入口在哪；
有子页的标签是青色可点的 `<a>`，点一下直达子页，没有的显示「本页无 · 详见门户页导航」。
注入/还原：`python3 tools/inject_subnav.py`（`--remove` 还原成原来的两枚信息 chip，
原始标记存在注释备份里）。

## 首屏加载慢属正常

实验室页面运行在沙箱 iframe 中、不共享浏览器缓存，每次打开都会重新下载 echarts
（约 10–30 秒，视网络情况），耐心等待即可。
