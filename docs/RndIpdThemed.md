# 研发管理专题样板间 · 设计基线（契约文档）

> **契约版本 v1.0（2026-08-20）**。本文是研发管理专题（`screens/rnd-ipd/`）开发前的设计基线，
> 也是全部并行产页任务的**唯一权威契约**：基准盘数字、页名、前缀、轮播顺序、下钻锚点以本文为准。
> 页面实现与本文冲突时，**裁决恒为「改页面向契约对齐」**；契约变更只能在波次边界修改本文并 bump 版本号。
> 沿用公共资金/厨电专题的三层范式。全部数据为**模拟数据**，与任何真实企业无关。

## 1. 项目定位与范围

- **题材**：科技集团研发管理——顶层 IPD 治理（组合/管道/需求/投入）＋ 微观敏捷执行（Scrum/Kanban/XP·DevOps），
  覆盖软件、硬件、云端、AI 四域协同研发，总部 + 多地研发中心组织形态。
- **规模**：29 块屏 = 1 门户 + 17 专题页（含 1 块等距数字孪生专题页）+ 11 二级详情子页（含 1 块园区数字孪生子页）。
- **目录**：`screens/rnd-ipd/`，文件命名 `大屏样板间-研发<主题>1920.html`。
- **三段式叙事**：一期 IPD 顶层治理（IPMT 视角）→ 二期敏捷执行（团队视角）→ 三期软硬云AI多域协同 → 四期组织与资产。

## 2. 虚构主体与数据设定

### 2.1 业务设定

虚构主体「**云麓智联科技**」（与厨电专题的「云麓厨电」同宇宙但**不勾稽**，数字各自独立）：

- **四条产品线**：智家终端（智能家居硬件）、云平台服务、AIoT模组、行业方案。
- **IPD 六阶段**：Concept → Plan → Develop → Verify → Launch → LCM（生命周期管理）。
- **六站点**：北京总部、上海中心、深圳中心、成都中心、西安中心、南京中心（纯国内，无海外）。
- **六职能**：软件、硬件、云平台、AI算法、测试、PM与管理。
- **12 个 Scrum 团队**（北斗七星＋四象＋紫微）：天枢、天璇、天玑、天权、玉衡、开阳、摇光、青龙、白虎、朱雀、玄武、紫微。
- **发布列车**：双月一班，年度基线 R26.2 / R26.4 / R26.6 / R26.8。
- **需求分层**：OR（原始需求）→ IR（初始需求）→ SR（系统需求）→ AR（分配需求）；SR→AR 是**拆分放大**（一条 SR 拆多条 AR）。

## 3. 三层导航

1. **门户**（研发经营驾驶舱）17 格宫格 → 各专题页；
2. **专题页**底部页码 + 左右箭头 + 25 秒自动轮播（← → 翻页、空格暂停），页头右上「二级子页」标签直达子页；
3. **父页下钻**：表格行/图形块点击 → `子页.html#<encodeURIComponent(对象名)>`；子页 `hashchange` + `resolveHash`（`decodeURIComponent` + 去空白归一化 + 可选 `HASH_ALIAS` 别名表）定位并高亮，带「返回上级」crumb（Esc 同效）。

**子页归属**：单产品线路标详情→产品组合与路标｜单项目IPD详情→IPD管道与评审｜需求条目台账→需求全生命周期｜
单团队冲刺详情→敏捷交付总览｜阻塞在制品台账→看板流动效率｜缺陷台账→质量与缺陷｜单集成基线详情→软硬云AI集成协同｜
单样机批次详情→硬件与样机｜单模型详情→AI模型迭代｜单中心详情→多中心布局｜园区数字孪生→单中心详情的**姊妹页**（孪生视角 ↔ 指标视角互链）。

## 4. 视觉语言

- **气质**：深靛夜空底 + 星蓝主色 + 琥珀强调——「星图/星轨」意象呼应多地协同研发，与厨电青橙工业风、公共资金金蓝政务风错开。
- **公共色板** `--rnd-*`：单一源 `shared/palette-rnd.json`（14 token + 6 色系列），
  经 `tools/sync_rnd_palette.py` 注入每页 `rndpalette:begin/end`（CSS `:root`）与 `rndpalette-js:begin/end`（JS `const PAL`）。
  页面在 PAL 块外手写便利别名层 `const C = Object.assign({}, PAL, { blueDeep: PAL["blue-deep"], textDim: PAL["text-dim"], grid: "rgba(96,140,255,.13)" })`。
- **其余规范**同仓库范式：1920×1080 舞台 `fitStage` 等比缩放、每页唯一 2 字母前缀、echarts CDN `cdn.jsdelivr.net/npm/echarts@6.1.0` + 资源守卫、
  数据全内联、CSS grid 模拟表格、mockflag 由工具注入（页头正中留空）。

## 7. 工程约定

### 7.1 页面骨架规矩（产页代理必守，抄基准页 P0 而非凭记忆写）

1. 暗底 `--rnd-bg` + `.xx-stage` 1920×1080 绝对居中 + `fitStage()`（`Math.min(innerWidth/1920, innerHeight/1080)`）；init 后不调 `chart.resize()`。
2. `:root` 内**先放** `rndpalette:begin/end` 标记块（占位即可，`sync_rnd_palette.py` 会填充），块外才是页私有变量；
   JS 主脚本内放 `rndpalette-js:begin/end` 标记块（`const PAL`）＋块外手写 `const C` 别名层。
3. 预置 `.xx-error` 告警条 + `if(!window.echarts){...return;}` 资源守卫；echarts 走 `cdn.jsdelivr.net/npm/echarts@6.1.0`，无其他外链、无 fetch。
4. 页头右侧结构 `…<div class="xx-chips">…</div><div class="xx-clock">…</div>`（chips 紧邻 clock）——subnav/carousel 注入锚点依赖；页头正中留空给 mockflag（工具注入，**不手写**）。
5. 数据全内联单源派生；契约数字逐字；二级拆分 Σ==上级；页尾勾稽自检：`const checks=[["描述",布尔],…]` 不过则 `console.warn("[页名] 勾稽自检未通过：",…)`。
6. 图表容器父链全 flex 或显式高度；`init` 之后才由 JS 填充的兄弟块必须写死高度（配 `min-height:0;overflow:hidden`）。
7. 进 option 的数据只放标量与数组，对象间用 id/name 关联，**严禁对象回指**（setOption 深拷贝遇循环引用整页全空）。
8. 表格用 CSS grid 模拟（`.xx-thead` + JS 生成行）；KPI 翻牌 countUp 缓动；`setInterval` 驱动活性，kiosk 不 teardown。
9. 子页另加：`hashchange` + `resolveHash` + 返回上级 crumb（`‹ 返回 <父页名>`，Esc 同效）；S10/S11 互挂姊妹 chip。
10. 交付前自检（grep）：前缀类名全仓唯一；`grep -c 'rndpalette:'`==2 且 `rndpalette-js:`==2；无 `fetch(|XMLHttpRequest`；`:root` 私有变量数==C 别名层外的引用一致。

**实测坑**：
- **注入链幂等要以「整链」为单位判**：drill/carousel 都往 `</style>` 前追加，单跑某一支会与
  mockflag 互换位次产生中途 diff；整链（drill→subnav→carousel→palette→mock_flag）跑完回到
  固定点 `[subnav→drill→carousel→mockflag]`，判据 = 整链前后全目录校验和一致。
- **轮播脚本 `let hidden=false` 是潜在 bug**：页面在后台标签页加载时收不到 visibilitychange，
  计时器照走、无人看时自己翻页。rnd 版已改为 `let hidden = document.hidden`；
  公共资金/厨电版同款问题已另立修复任务。
- 浏览器门禁中 `computer key Escape` 可能因焦点不在页面而丢失，判 Esc 行为要用
  `document.dispatchEvent(new KeyboardEvent(...))` 直接派发。

**导航规模变化**：轮播 4/17 页、subnav 4 父页（3 有子页 + 1 无）、drilldown 3 组 16 对象、

**实测坑**：
- ★ **注入链固定点要靠「钉锚点」而非「固定跑序」**：drill / carousel / mock_flag 三支都往
  `</style>` 前插块，每次重跑各自把自己顶到末位，三支轮流改写同一批文件、整链**永不收敛**
  （W3 实测三支均报「改写了文件」）。修法照搬 subnav 的做法给 drill 钉死锚点
  （subnav:begin → carousel:begin → `</style>` 逐级退化），固定点变为
  **[drill → subnav → carousel → mockflag]**，连续三轮校验和一致。
- ★ **切换器类子页要给 hash 定位加保持窗**：父页下钻进来后，kiosk 轮换会在 12–16 秒后把读者
  切到别的对象（实测点「玄武」→ 12 秒后变「紫微」，hash 也被 replaceState 覆盖）。台账类子页
  本就有「hash 后暂停 20s」，切换器类（dl/dj/cq）漏了，已统一补 `holdUntil` 门闩。
- **后台标签页 `requestAnimationFrame` 完全暂停**：翻牌数字会一直停在 0（不是中途值），
  且 rAF 里的 Promise 永不 resolve（javascript_tool 会超时）。验收数字必须让面板处于前台，
  否则会把环境效应误判成页面 bug。
