# 维护指南

改这个库时需要知道的目录约定与再生成命令。新建/修改成品大屏还要看根目录
[`CLAUDE.md`](../CLAUDE.md) 里的「样板间专题页范式」，公共资金专题的设计规范见
[`PublicFundsThemed.md`](PublicFundsThemed.md)。

## 目录结构

```
index.html                      索引页（入口，自动生成，不要手改数据区）
charts/                         图表方案画廊 39 个（ECharts视觉实验室-*.html）
screens/                        通用样板间 30 块 1920×1080 成品屏（10 总览 + 19 专题内容页 + 1 轮播多页组）
  public-funds/                 公共资金专题样板间 27 块（索引页归入独立分组）
                                  13 块专题页串成自动轮播（tools/inject_carousel.py 注入导航）
                                  13 块二级详情子页，入口由 tools/inject_drilldown.py 注入到父页
                                  页面互链都是同目录相对路径，整组搬家不用改 href
components/                     大屏组件 3 个（装饰型组件 / 生产型业务组件 / 适配脚手架）
palettes/                       配色陈列 2 个（21 套风格皮肤 / 12 套行业主题）
studies/                        选型与效果对比 2 个（长三角增速标识选型 / 玻璃材质对比）
docs/                           文档
shared/                         共享资源（由 tools/ 脚本再生成，不手编）
  themes.js                     33 套主题数据（复制/换肤共用）
  geo-data.js                   地图边界数据（全国/长三角/江苏/三板块，内嵌用）
  lab-addons.js                 复制按钮 + 主题切换的公共模块
tools/                          维护脚本（日常使用不需要）
  build_index.py                重新生成 index.html（新增文件后跑一次）
  inject_mock_flag.py           给全部样板间顶边注入「模拟数据」标识（幂等，--remove 可摘掉）
  inject_carousel.py            向公共资金专题 13 页注入轮播导航（幂等；改停留秒数或页序后重跑）
  inject_drilldown.py           向 10 个父页注入「点击行/卡片/画布分块下钻到子页」入口（幂等，写盘前预检锚点）
  inject_subnav.py              把 13 个父页页头右上的 chip 换成「二级子页」导航标签（幂等，--remove 可还原）
  labtool.py                    实验室 srcdoc 解码/回写
  inject_addons.py              向实验室注入公共模块
  wrap_lab.py                   新实验室内页打包成外壳格式
  extract_themes.py             从配色文件重新提取主题数据
  fetch_geo.py                  重新抓取地图边界数据
```

## 两类产物，编辑方式不同

- **实验室**（`ECharts视觉实验室-*.html`、`大屏组件实验室*.html`、配色实验室）：外层是带严格 CSP 的
  外壳，真实内容 HTML 转义后内嵌在 `<iframe srcdoc="...">` 里。**不要直接编辑 srcdoc**，用
  `labtool.py decode/encode` 走内页。
- **样板间**（`大屏样板间-*.html`）：纯自包含单文件，直接用编辑器改。

## 常用命令

```bash
# 在内容目录里新增/改名/修改 *.html 后，重建索引（幂等）
# 注：只原地更新 index.html 的数据区（卡片 manifest、分类、徽章色、统计行），
#     页面顶部/底部的说明文字是手工维护的，重建不会覆盖
# 新增分类目录时，要把目录加进 tools/build_index.py 的 CONTENT_DIRS
python3 tools/build_index.py

# 新增样板间后，补上顶边「模拟数据」标识（幂等；--remove 可整批摘掉）
python3 tools/inject_mock_flag.py

# 修改某实验室内容：解码 → 编辑 <文件名>.inner.html → 回写
python3 tools/labtool.py decode charts/ECharts视觉实验室-柱状图8.html
python3 tools/labtool.py encode charts/ECharts视觉实验室-柱状图8.html

# 更新了 shared/lab-addons.js 或 themes.js 后，重新注入（幂等）
python3 tools/inject_addons.py charts/<实验室.html> '{"headSelector": ".xxx-panel-header", "chartSelector": ".xxx-chart"}'

# 再生成共享资源（改了源文件才需要）
python3 tools/extract_themes.py    # 从两个配色实验室重抽 33 套主题 → shared/themes.js
python3 tools/fetch_geo.py         # 从阿里 DataV 抓边界 → shared/geo-data.js（需联网 + 可选 shapely）
```

## 验证方式

无自动化测试。改完后：

1. 跑 `build_index.py`，核对打印的「分类 / 方案数 / 大小」汇总是否符合预期；
2. 起 HTTP 服务后浏览器逐页目检：控制台零报错、窗口缩放等比、图表渲染正常、数字勾稽对得上。
