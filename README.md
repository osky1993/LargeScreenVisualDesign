每张方案卡片可一键复制可运行的配置。无构建系统、无 npm 依赖，运行时只从 CDN 加载 echarts。

**在线预览：<https://osky1993.github.io/LargeScreenVisualDesign/>**（GitHub Pages，随 master 分支自动发布）

## 快速开始

所有页面都是自包含的静态 HTML，**双击 `index.html` 用 Chrome / Edge 打开即可**，
从索引页跳转到各个实验室。

更推荐起个本地静态服务（缓存、路径、刷新都更友好）：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/index.html>。任何静态服务器都行，例如 `npx serve .`。

> 需要联网：页面运行时从 CDN（jsdelivr / unpkg）加载 echarts，离线打开图表不渲染
> （页面会提示「ECharts 资源加载失败」）。地图边界数据已内嵌，不额外联网。
